请用离线事件模拟服务代理连接池，检查连接交接时认证状态如何变化。连接以永久 ID 和使用代次登记，生命周期为空闲、预留、认证、在用、待清除或关闭。安全上下文由租户、对端身份版本、信任配置版本和用途级别构成。只有四项均匹配且尚未超过认证时限的上下文可直接复用；不匹配先清除，再用当前版本发起认证。清除与认证的异步完成消息分别携带连接代次、一次性操作 ID 及预期配置版本。取消或超时后旧消息仍可能到达，不能让连接回到过时状态。对端被撤销时，相关未完成和在用请求必须收到终止回执，此后不能交付完成结果；其他租户不被连带终止。
ingest 以固定输入的逻辑时钟和有序事件批处理，优先分配可直接复用的空闲连接，再考虑必须清除的空闲连接，同类按连接 ID 字典序选择。待处理请求按提交顺序，在同批结束后统一再次调度。一次应用原子落事件、连接状态与回执；重复 ID 同内容返回原回执，冲突拒绝整批。explain 可还原某请求的状态迁移和迟到完成为什么无效。至少覆盖两租户依次使用一连接、认证完成和撤销同一批、取消与复用时旧完成迟到、修改一个用途级别、冷却清除失败、进程中途退出和恢复时重复完成。规则以输入的抽象事件执行，禁止依赖网络或真实代理。

把代理扩成两个模拟工作进程可抢占的持久连接池。每个进程只有带代次和截止时刻的控制租约，租约失效后另一进程接管。旧进程随后送来的清除或认证完成与新进程抢先复用写同一连接时，必须同时核对连接代次、操作 ID 和控制租约代次。工作进程退出与正常的业务撤销要分开处理：未完成的外部操作不能被当作已完成，接管时先落一个待确认状态，可经幂等重发完成命令，但不会让任务收到第二份终止或成功回执。新增明确的处理协议：输入一个租户同时对多个连接发起分组预留；全部找到并同时匹配才整体转为已预留，仅读到部分候选不能占住连接阻塞其他队列。遍历队首以外的申请时记录先前不满足的原因，直到逻辑时间或状态变化再次调度。使用 SQLite 原子写入租约、事务性待确认清单和稳定回执。测试用同步屏障构造接管与撤销同刻、组内仅一条可用、首批等待时后批仍可前进、两进程同时抢同组、写提交前退出和提交后响应丢失。独立校验任何历史前缀都没有跨租户状态复用。

用本地虚构的连接和进程事件制作可直接运行的样例。从空仓库实现，在 Windows 原生 Python 3.12 上以标准库和 CPU 执行。模拟器通过 `python -m solution <命令> CASE.json` 接收案例，访问持久连接池的命令指定 `--db DB.sqlite`。把 UTF-8 JSON 结果写至标准输出，同一逻辑输入应可重复得到一致结果。输入结构错误须明确错误码与字段位置。交付含完整输入输出定义和复现命令的 README，以及可用 `python -m unittest discover -s tests -v` 跑通的断言测试。
